# Policy candidates

A **descriptive** queue: recurring violations and classes of mistakes that an
enforcement (a hook, a CI check, a skill) could prevent. An entry here is NOT yet
a hook or skill — writing one is a separate, human-driven step.

Each candidate is its own file, `policies/candidates/<id>.md`:

```
# <id>
- policy: <one sentence — the rule that must always hold>
- artifact: skill | hook | both
- scope: cross-repo | repo:<name>
- seen: <count of distinct sources>
- status: candidate | triage | approved→<path> | rejected:<reason>
- evidence:
  - <source daily/incident> — <date> — <one sentence>
```
